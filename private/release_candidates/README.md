# Private release candidates

Files here are non-public staging artifacts. Presence in this directory does not make a catalog product purchasable.

Set 01 RC1 now has a separately imported exact checksum-bound release authorization. It remains here because authorization to release is not authorization to sell.

A candidate may move to `private/releases/` only after an immutable commercial release manifest is promoted, an explicit positive integer price and sale authorization are approved, and the full storefront/payment/download checks pass.
